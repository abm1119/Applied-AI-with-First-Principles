# Master Daily Checklist
**Use this every single day.** Print it or keep it open.

Copy the template below into your notes or a daily log each day.

---

## Daily Template (Copy this every day)

```markdown
# Day ___ — Date: ___________

## Pre-Block (30 seconds)
- [ ] Phone on silent / in another room
- [ ] Water or coffee ready
- [ ] Today’s focus sentence written:

> Today I will _______________________________

---

## CURRICULUM BLOCK (6:00 – 8:30 PM)
Open: `09-DEEP-DAILY-CURRICULUM.md`

- [ ] Reviewed yesterday’s notes / code (10 min)
- [ ] Completed the learning part of today’s checklist
- [ ] Completed the hands-on part
- [ ] Wrote short notes or comments in code
- [ ] Captured any content ideas into `content-ideas.md`
- [ ] Wrote tomorrow’s one-sentence goal
- [ ] Committed code (if any was written)

**Curriculum output today:**
- 

---

## LINKEDIN BLOCK (8:45 – 9:30 PM)
- [ ] Opened `content-ideas.md`
- [ ] Chose one idea
- [ ] Wrote and published (or fully drafted) the post
- [ ] Added the post to content log if desired

**Post topic today:**
- 

---

## RESEARCH BLOCK (11:30 PM – 12:30 AM)
Open: `10-DEEP-DAILY-RESEARCH.md`

- [ ] Selected one high-quality material
- [ ] Read with focus for ~35 minutes
- [ ] Wrote full notes using the template
- [ ] Wrote the one-sentence takeaway
- [ ] Saved the note file
- [ ] Tagged it properly

**Research takeaway today:**
- 

---

## PRACTICAL / NIGHT CODING (12:30 – 2:00 AM) — Optional but recommended
- [ ] Continued implementation from the learning block
- [ ] Or cleaned previous code
- [ ] Or prepared for the weekend project
- [ ] Committed progress

---

## End of Day Shutdown (2 minutes)
- [ ] All checkboxes above reviewed
- [ ] Progress feels honest (not inflated)
- [ ] Tomorrow’s focus is clear
- [ ] Closed the laptop

**One word for today:** _______________
```

## How to Use This File

1. Every morning or at the start of the learning block → copy the Daily Template.
2. Fill it as you go.
3. On Sunday → fill the Weekly Template.
4. Be honest. The system only works if the checkboxes reflect reality.

This is your main control panel for the entire 100 days.
