# Deep Daily Research Checklists
**Research track only.** Completely separate from Curriculum.

Use this file during the 11:30 PM – 12:30 AM block.

---

## Daily Research Protocol (60 minutes exactly)

| Minute | Action | Details |
|--------|--------|---------|
| 0–5 | Select material | Choose one paper or long technical post |
| 5–40 | Focused reading | No highlighting everything. Read for understanding |
| 40–55 | Write notes | Use the template below |
| 55–60 | One-sentence takeaway + tags | Force clarity |

---

## Phase-Aligned Research Focus

### Days 1–14 — Landscape & Foundations
**Goal:** Build a map of the field.

Suggested topics:
- What AI Engineering is becoming
- Current state of LLM application architecture
- Common failure modes in production LLM apps
- Tooling landscape overview

Daily checklist:
- [ ] Material selected
- [ ] 35 min focused reading completed
- [ ] Notes written using template
- [ ] One-sentence takeaway written
- [ ] File saved in research-notes/

### Days 15–35 — Prompting, Structured Output, Tools
**Goal:** Deep understanding of the application layer.

Suggested topics:
- Prompt engineering papers and real-world analyses
- Structured output methods and reliability
- Tool calling design patterns
- Memory systems for conversational agents

Daily checklist: same as above + 
- [ ] Explicitly noted at least one idea I can test in code this week

### Days 36–55 — Retrieval & Evaluation
**Goal:** Strong mental models for RAG.

Suggested topics:
- Chunking research
- Embedding model comparisons
- Hybrid search
- RAG evaluation methods (RAGAS and others)
- Failure modes of retrieval systems

Daily checklist: same +
- [ ] Noted how this changes (or doesn’t change) my current RAG plans

### Days 56–70 — Agents
**Goal:** Understand agent design beyond the hype.

Suggested topics:
- ReAct and its successors
- Planning vs reacting
- Multi-agent coordination papers
- Safety and control of agents
- Real production agent case studies

### Days 71–85 — Production & Observability
**Goal:** Learn how real systems are monitored and improved.

Suggested topics:
- LLM observability tools and practices
- Evaluation in production
- Cost and latency optimization case studies
- Feedback loops and continuous improvement

### Days 86–100 — Synthesis + Personal Interest
**Goal:** Connect everything and go deeper on what interests you most.

You may choose one deeper thread (agents, evaluation, education applications, etc.) and stay with it.

## Strict Rules for this Track

1. This hour is reading + writing notes only. No coding.
2. Do not open the Curriculum files during this hour.
3. If the paper is too hard, switch to a high-quality blog post that explains it. Still counts.
4. Quality of the one-sentence takeaway is the most important metric.
5. Never skip the notes. Reading without writing is mostly wasted.
