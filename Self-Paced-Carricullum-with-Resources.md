# Advanced Phases (Previously Missing)

These are the critical gaps for reaching senior / production level in 2026.

---

## Phase 13 – Observability & Production Debugging

- Agent tracing (LangSmith, Arize Phoenix, OpenTelemetry)
- Cost & latency tracking per step / trajectory
- Token usage dashboards
- Failure analysis of tool calls
- Logging structured outputs and decisions

---

## Phase 14 – Inference Optimization & Serving

- vLLM / TensorRT-LLM / SGLang
- Quantization (GGUF, AWQ, GPTQ, EXL2)
- Continuous batching & speculative decoding
- Proper streaming responses
- GPU vs CPU cost trade-offs

---

## Phase 15 – AI Infrastructure & Deployment

- Deep async patterns + background workers (ARQ, Celery, Redis queues)
- Multi-stage Docker builds for AI services
- Deployment platforms (Modal, Fly.io, Railway, basic Kubernetes)
- Autoscaling for LLM workloads
- Secrets management & environment strategy

---

## Phase 16 – Security, Cost Engineering & Advanced Context

**Security**
- Prompt injection defenses
- Tool / MCP authorization & sandboxing
- Data leakage prevention
- Rate limiting + abuse detection
- PII redaction

**Cost Engineering**
- Semantic caching
- Model cascading / routing (cheap model first)
- Batch inference
- Budget controls & alerts

**Advanced Context Engineering**
- Context compression & hierarchical memory
- Long-context vs RAG decision making
- Dynamic context assembly
- State management for long-running agents

**Multi-modal**
- Vision + tool calling
- Document + image understanding
- Basic audio / voice agents

---

## Recommended Learning Order

1. Phases 1–4 → Solid backend + UI foundation  
2. Phases 5–9 → LLM + RAG + Agents mastery  
3. Phases 10–12 → Evals, fine-tuning, harness  
4. Phases 13–16 → Production hardening  

**Capstone Ideas**
1. FastAPI + Postgres social API with auth  
2. Streamlit / Gradio UI on top  
3. Add RAG over documents + posts  
4. Turn into agent with MCP tools + memory  
5. Add observability, evals, guardrails, and deploy
